PCB Defect Auditor

Upload a photo of a bare printed circuit board and a YOLOv8 model finds and outlines six kinds of manufacturing defect: open, short, mousebite, spur, spurious copper and pin-hole.

  • API documentation (/docs)
  • Source code on GitHub

Waking up the server (free hosting sleeps when idle). This can take up to 60 seconds.

Trained on DeepPCB (Kaggle repackaging, 1,200/150/150 split). Not validated on real factory images.
